# 🎮 Rock Paper Scissors Game

## 📌 Project Overview
This is a simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. The player competes against the computer with real-time game results, score tracking, and an attractive user interface.

## 🚀 Features
- ✊ Rock, Paper, Scissors gameplay
- 🤖 Random computer choice
- 📊 Live score tracking
- 🏆 Winning streak counter
- 📜 Match history
- 🌙 Light/Dark mode
- 🏅 Achievement badges
- 🎨 Modern responsive UI
- ⏳ Countdown animation
- 🔄 Reset game functionality

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
