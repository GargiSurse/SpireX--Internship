# Responsive Navbar

A modern and responsive navigation bar built using HTML, CSS, and JavaScript. The navbar automatically adjusts its layout to provide a smooth user experience across desktop, tablet, and mobile devices.

## Features
- Responsive Design
- Glassmorphism Navbar
- Mobile Hamburger Menu
- Smooth Hover Effects
- Animated Gold & Black Theme
- Fully Responsive Layout

## Technologies Used
- HTML5
- CSS3
- JavaScript
