# Portfolio Card

A modern and responsive personal portfolio card designed using **HTML, CSS, and JavaScript**. This project focuses on creating a clean, professional UI with a glassmorphism-inspired design, smooth layout, and responsive behavior for different screen sizes.

## 🚀 Features

* Responsive portfolio card design
* Modern UI with glassmorphism effects
* Profile section with introduction
* Skills and role showcase
* Clickable social/contact links
* Clean and professional layout
* Mobile, tablet, and desktop friendly design
* Interactive elements using JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts (Poppins)
* Font Awesome Icons

## 📂 Project Structure

```
Portfolio-Card/
│
├── index.html

├── script.js
│
└── images/
    └── profile.jpg
```

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the portfolio card.

## 🎯 Purpose

The purpose of this project is to practice frontend development skills by building a visually appealing and responsive portfolio component using core web technologies.
