# 🔐 Login & Signup Form UI

A responsive Login & Signup Form UI built using HTML, CSS, and JavaScript. The project allows users to switch between Login and Signup forms with client-side validation for a smooth user experience.

---

## 📌 Project Overview

This project demonstrates the fundamentals of front-end web development by creating a modern authentication interface. It includes form validation, responsive design, and a clean user interface using only HTML, CSS, and JavaScript.

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Login and Signup form switching
- Client-side form validation
- Email format validation
- Password length validation
- Confirm password matching
- Success and error messages
- Modern and clean user interface
- Smooth hover effects and transitions

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📋 Validation Included

### Login Form
- Email is required
- Valid email format
- Password is required
- Password must contain at least 6 characters

### Signup Form
- Full Name is required
- Valid email format
- Password must contain at least 6 characters
- Confirm Password must match Password
- Displays success or error messages
