# ♻️ Smart Waste Management Dashboard

A modern and responsive Smart Waste Management Dashboard built using **HTML, CSS, JavaScript, and Chart.js**. The dashboard helps monitor waste bin levels, collection status, recycling data, and live updates through an interactive and user-friendly interface.

## 🚀 Features

- 📊 Interactive Charts using Chart.js
- 🗑️ Waste Bin Monitoring Dashboard
- 🚛 Live Truck Status Updates
- 🤖 Smart AI Recommendations
- 🌱 Carbon Saved Counter
- ⏰ Real-Time Clock
- 🌙 Light/Dark Mode
- 📈 Collection & Recycling Statistics
- 📱 Fully Responsive Design
- ✨ Clean and Modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
